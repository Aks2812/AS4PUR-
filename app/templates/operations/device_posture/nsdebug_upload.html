Where to get this file

Collected manually from the Netskope tenant UI: Settings → Security Cloud Platform → Netskope Client → Devices → [user] → Collect log. Automated retrieval isn't available yet.

Not every check type this platform supports will necessarily appear in a given log - macOS and Android, in particular, often stay silent for check types with no configured rule rather than logging a "no rule" line the way Windows does. A check that's applicable to the platform but wasn't observed in this log is shown as its own distinct outcome below, never silently left out.
