Expected file format

An Excel (.xlsx) file with a header row containing exactly these columns: No, App Name, Hosts (IP/CIDR), Ports (Protocol/Port).

  • Hosts accepts, comma-separated: a plain IP, a CIDR block, a full range (192.0.2.1-192.0.2.20), a shorthand last-octet range (192.0.2.1-20), an FQDN, or a labeled host (LABEL-192.0.2.1/32).
  • Ports accepts, comma-separated: tcp/443 or a range like tcp/8000-8010.
